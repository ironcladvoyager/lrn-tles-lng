# ☕ Real-Life English Situations & Roleplay (Repository 3 / Variety 3)

Automated video generator for **Real-World Conversational Roleplays** (Ordering at coffee shops, hotel check-ins, job interviews, airport navigation) rendered in 9:16 vertical video.

## 🌟 Key Features
- **Dual-Speaker Roleplay**: Natural back-and-forth between customer/guest and staff/host.
- **Dynamic Speaker Bubbles**: Highlights who is currently speaking with active badge states.
- **Pro Native Tip**: Dedicated bottom card sharing etiquette and natural phrase formulas.
- **High Utility Value**: Tailored for travelers, immigrants, and daily English speakers.

## 🚀 How to Run
```bash
# 1. Generate roleplay video
python run_generator.py

# 2. Publish to Facebook Page
python publish_facebook.py output/run_XXXX/situation_roleplay_final.mp4 output/run_XXXX/metadata.json
```

## 📱 Recommended Facebook Page Target
- **Page Concept**: *Real World English Academy / Everyday English Dialogues*
- **Target Audience**: Anyone wanting practical, confidence-building dialogues for travel, work, and social life.
